# Mystic China 视觉设计说明

本稿将 MysticChina 设计为面向外国读者的中国文化图鉴与社区。阅读、地域探索、个人见闻、创作收益、账号收藏和文化小游戏组成一个完整体验。交付包含 30 个手机页面、可交互状态和设计说明；本阶段只交付设计。

## 打开与评审

直接用浏览器打开同目录的 [index.html](./index.html)，或在项目根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory design/mystic-china
```

访问 <http://127.0.0.1:8765>。

- **全部页面**：按产品路径浏览 30 个手机页面。每个手机内可单独滚动，点击“交互预览”进入大图。
- **交互预览**：左侧切换页面，手机内执行操作，右侧查看设计意图和关联页面。可切换访客 / 已登录创作者，或重置示例。
- **设计说明**：查看视觉规范、信息结构、规则及验证边界。
- `#discover`、`#wallet` 等地址片段可直接打开具体页面。
- 手机宽度下使用单列总览；桌面宽度下使用多列设计画板。

邮箱登录可使用任意格式有效的示例邮箱；验证码为 **246810**。社交登录仅展示确认流程，不访问 Apple / Google。主题偏好保存于当前浏览器，刷新后保留；账号、草稿、交易和收藏均为当前页面内的临时演示状态，刷新即重置。请勿在原型中输入真实身份或财务资料。

## 产品定位与视觉语言

**产品主张：** 从风景看见生活，从文字理解文化，让每个人都能贡献自己的中国故事。

目标人群包含文化爱好者、计划来华的旅行者、在华旅居者、海外中文初学者和希望分享经历的创作者。以英文作为默认内容语言，保留中文专有名词、拼音、术语解释和中文对照；更多语言在设置中说明，不伪装成已经具备完整翻译的产品。

### 中国红的颜色层次

- **红色定调**：状态栏和置顶导航使用正红，搭配暖白标题、图标；主按钮、选中导航、选中标签沿用同一主红。
- **留白承托**：大面积阅读区使用暖米白，卡片使用更浅的瓷白 `#FFFDFA`，浅朱色 `#F8E5DE` 连接卡片和选中状态。设计目标约为 70% 暖色留白、25% 主红、5% 金色细节，随具体页面调整。
- **金色点睛**：付费徽标使用浅金底 `#F6E9CC` 和深金字 `#805411`；钱包在深绛红 `#781B20` 上用浅金展示余额。不用浅金写长段正文。
- **青色平衡**：地域与自然内容使用玉绿；成功、已结算与答对使用独立的绿色语义，不把所有状态都染成红色。
- **可读的正文**：深褐正文、暖灰说明文字、不透明导航背景，保持图片和长文的阅读层级。
- **适当的克制**：灾难、纪念与重建页不使用礼花或庆祝动效，保持原有内容提示和来源标识。

### 所有主题共同遵守

背景、卡片、导航、按钮、选中状态、表单、弹层、钱包、小游戏和空态一起切换。深色主题使用真正的深色卡片与表单，避免保留大面积浅蓝组件。摄影保留原始色彩，图片上的白色文案和遮罩独立于主题。成功、警告、错误通过图标和文字辅助表达，付费与余额的含义不随颜色变化。卡片圆角 6px、左右各 12px 和导航栏置顶规则继续保留。

## 六条建议评审路径

1. **游客探索**：发现 → 分类 → 历史时间轴 / 人物 → 详情 → 词语注释 → 中文对照。
2. **地域发现**：Places → 广西 → 桂林 / 龙胜选择 → 当地文化分类 → 当地见闻。无需开放定位。
3. **支持创作者**：Stories → 付费试读 → 登录 → 同一订单 → 同意条款 → 示例支付确认 → 全文 → Me / Purchased。
4. **投稿变现**：登录 → 编辑 → 原创声明 → 免费/付费 → 预估所得 → 投稿审核 → Creator studio → 钱包 → 提现确认 → 申请进度。
5. **游戏学习**：Play → 山字识义 → 错误提示 → 正确答案 → 结果文化解释 → 登录保存印章。

6. **名著阅读**：Discover / Culture atlas → The Four Classics → 任选名著 → 第一至第三回 → 翻幅 / 中英对照 / 词语与来源。

## 四大名著连环画

直接访问 <http://127.0.0.1:8765/#classics>。发现页和文化图鉴均有入口。

四部名著各制作原著前三回，每回六幅，共 **12 回、72 幅**。采用细线水墨与矿物淡彩的连环画形式；画面不内嵌字幕，英文、中文及双语叙述由页面排版，便于外国读者阅读。每回有原始回目、三条词语注释、人物介绍和底本链接，明确标注“节选改编 / abridged retelling”。本期免费浏览，不要求登录。

目录 → 逐幅阅读 → 下一回；可从顶部选回、点击画幅序号跳读。第三回结束返回该书目录，不虚设第四回。切换中国红、青花蓝、墨夜金时保留所在书、回、幅、语言和滚动位置；顶部导航继续固定。阅读进度只保留当前原型会话。

原著章节、版本说明和图像生成记录见 [CLASSICS.md](CLASSICS.md)；完整双语脚本见 [classics-data.js](classics-data.js)。

## 产品状态细节

- 每个页面的顶部导航栏固定在手机状态栏下方；正文向上或向下滚动时，页面标题、返回按钮及右侧操作始终可见。导航栏使用不透明背景覆盖经过其下方的内容，底部主导航继续固定。
- 公开浏览无需账号。收藏、购买、投稿、钱包等按需登录，成功后返回触发页面；首次收藏会继续完成。
- 免费与付费是单篇阅读权限，付费不额外要求订阅。已购买文章进入已购列表，设置提供恢复购买入口。
- 投稿提交后进入审核；需修改时展示具体原因和返回编辑。审核通过前不承诺上架或收益。
- 编辑知识、社区见闻、文学传说、民俗信仰需各自标注。历史资料给出来源，个人体验明确属于作者视角。文化术语解释不以刻板印象替代地区差异。
- 原生数字内容购买展示适用商店流程；银行卡支付作为可用 H5 渠道的设计说明，不在原生购买页假装可绕过商店购买。
- 钱包区分待结算与可提现。示例账面：可提现 $128.40 + 待结算 $24.00 + 已提现 $279.70 = 累计净收益 $432.10。
- 示例提现 $50 后，可提现显示 $78.40，并新增处理中记录；再次确认会回到当前申请，不重复扣减。
- 金额包含最低提现、超余额、小数位和负值校验；验证码、必要授权及购买条款也有反馈。
- 提现申请受理不表示到账。失败、银行退回与费用变更等实际财务流程，在支付服务确定后继续设计。
- 学习印章不与现金挂钩。当前小游戏为识义题，实际产品原有书写游戏保留为后续接入资源。
- 覆盖式弹层保留文章实际节点和滚动位置。完整 App 的 Tab、二级页返回状态需在正式实现时继续遵循共享框架规范。

| 待确认项 | 确认内容 | 推荐 |

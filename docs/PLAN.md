# 一剪（yijian）项目计划文档

## 概述

本计划文档规划了「一剪」视频剪辑应用的完整开发路径，分为四个阶段迭代推进。当前聚焦**一期**交付。

---

## 阶段总览

| 阶段 | 时间估算 | 核心目标 | 交付物 |
|------|---------|---------|--------|
| **一期** | 第1-2周 | 视频预览与播放 | 可运行的视频播放Demo |
| **二期** | 第3-5周 | 视频编辑基础能力 | 裁剪、滤镜、文字 |
| **三期** | 第6-8周 | 高级编辑功能 | 时间轴、音频、转场 |
| **四期** | 第9-10周 | 导出与优化 | 视频导出、性能优化 |

---

## 一期详细计划（当前）

### 目标
实现视频预览、播放、暂停核心链路，构建可运行的跨平台 Demo。

### 里程碑

```
M1: 项目脚手架搭建 ── 第1天
   ├── 项目目录结构创建
   ├── Gradle 构建配置
   └── KMM 模块初始化

M2: 基础框架搭建 ── 第2天
   ├── 主题系统（深色主题）
   ├── 通用组件（TopBar、BottomBar、ProgressBar、IconButton）
   ├── 页面路由
   └── BasePager 封装

M3: 媒体库页面 ── 第3天
   ├── 视频列表页面
   ├── Mock 数据
   └── 视频缩略图组件

M4: 视频播放器核心 ── 第4-5天
   ├── 平台桥接接口定义
   ├── Android：ExoPlayer 集成
   ├── iOS：AVPlayer 集成
   ├── 播放状态管理
   └── 播放器 UI 组件

M5: 视频预览页面 ── 第6天
   ├── 全屏预览页面
   ├── 播放/暂停控制
   ├── 进度条（可拖动）
   ├── 时间显示
   └── 控制栏显隐切换

M6: 集成与验证 ── 第7天
   ├── 页面路由串联
   ├── 播放状态同步
   ├── 边界情况处理
   └── 集成验证
```

### 任务分解

#### 第1天：项目脚手架
- [ ] 创建 yijian 项目根目录
- [ ] 配置 `settings.gradle.kts`（rootProject、submodules）
- [ ] 配置 `build.gradle.kts`（根构建脚本、插件声明）
- [ ] 配置 `gradle.properties`（KMM、Android 参数）
- [ ] 配置 `shared/build.gradle.kts`（KMM 多平台配置、Kuikly 依赖）
- [ ] 配置 `androidApp/build.gradle.kts`（Android 宿主）

#### 第2天：基础框架
- [ ] 定义主题色板（Colors.kt）
- [ ] 实现 BasePager 基类
- [ ] 实现 TopBar 导航栏组件
- [ ] 实现 BottomBar 底部控制栏组件
- [ ] 实现 ProgressBar 进度条组件
- [ ] 实现 IconButton 图标按钮组件
- [ ] 实现 VideoThumbnail 视频缩略图组件

#### 第3天：媒体库
- [ ] 定义 VideoInfo / MediaItem 数据模型
- [ ] 模拟视频列表数据
- [ ] 实现 MainPage（视频网格列表）
- [ ] 实现视频项点击事件

#### 第4-5天：播放器
- [ ] 定义 IVideoPlayer 桥接接口
- [ ] 定义 PlayerState 枚举（IDLE/LOADING/READY/PLAYING/PAUSED）
- [ ] 实现 AndroidVideoPlayer（基于 Android 原生 MediaPlayer）
- [ ] 实现 IOSVideoPlayer（基于 AVFoundation）
- [ ] 实现 PlayerController（状态管理、命令封装）
- [ ] 实现 VideoPlayerView（播放器 ComposeView）

#### 第6天：预览页面
- [ ] 实现 PreviewPage（全屏视频预览）
- [ ] 播放/暂停按钮交互
- [ ] 进度条状态绑定与拖动
- [ ] 时间格式化显示（mm:ss）
- [ ] 点击画面切换控制栏显隐（动画过渡）

#### 第7天：集成
- [ ] 配置页面路由（SplashPage → MainPage → PreviewPage）
- [ ] 跨页面数据传递
- [ ] 边界处理（空状态、加载态、错误态）
- [ ] 代码审查与清理

## 二期规划（预览）

### 目标
视频裁剪、滤镜特效、文字叠加基础编辑能力。

### 核心功能
- [ ] 视频裁剪：选择时间范围、片段分割
- [ ] 滤镜系统：LUT 滤镜、色彩调节（亮度/对比度/饱和度）
- [ ] 文字叠加：添加/编辑文字、字体选择、位置调整
- [ ] 编辑预览：编辑效果实时预览

### 关键技术
- 基于 GPU 的滤镜渲染（OpenGL/Metal）
- 文字渲染引擎
- 编辑状态管理与撤销/重做

## 开发规范

### 代码风格
- 遵循 Kotlin Coding Conventions
- 包名：`com.yijian.*`
- 文件名：PascalCase（类名与文件名一致）
- 响应式字段使用 `by observable` 语法

### 命名规范
- **Pager**：`XxxPage.kt`，继承 `BasePager`
- **ComposeView**：`XxxView.kt`，继承 `ComposeView`
- **Model**：`XxxInfo.kt` 或 `XxxItem.kt`
- **接口**：`IXxx.kt` 前缀 I
- **资源**：`xxx_xxx` 下划线命名

### 提交流程
```
feat: 添加视频播放器核心组件
fix: 修复进度条拖动时偶现闪退
refactor: 重构播放状态管理
docs: 更新架构文档
```

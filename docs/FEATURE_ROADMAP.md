## 各功能详细说明

---

### 🈶 文字与书法类

#### 1. 汉字闯关游戏
- **描述**：按难度分级（小学 / 初中 / 高中），通关制，每关若干字，写完得分
- **技术方案**：复用现有 HanziWriter `randomOrder` 模式，新增关卡数据 JSON
- **核心体验**：写对 → 下一字 → 通关动画；写错 → 提示 → 重写
- **数据需求**：各年级汉字表（教育部标准字表，约 3500 字）
- **优先级**：🔴 P0

#### 2. 汉字字源故事
- **描述**：每个字配甲骨文 → 金文 → 小篆 → 楷书的演变图，讲述字的来历故事
- **技术方案**：WebView + 静态 JSON 数据，演变图用 SVG 动画展示
- **核心体验**：点击一个字，看它「从图画变成文字」的演变过程
- **数据需求**：常用字字源数据（可引用开源汉字演化数据库）
- **优先级**：🟠 P1

#### 3. 汉字听写测试
- **描述**：播放汉字读音（TTS），用户用手写识别写出对应字，系统判断对错
- **技术方案**：HanziWriter 练写 + Android TTS / 预录音频
- **核心体验**：听音写字，模拟课堂听写场景
- **优先级**：🟠 P1

#### 4. 偏旁部首训练
- **描述**：专门练习「氵、木、口、心」等高频偏旁，同时展示含该偏旁的常见字
- **技术方案**：HanziWriter 单字练习 + 偏旁关联字列表
- **优先级**：🟡 P2

#### 5. 书法字帖临摹
- **描述**：提供颜（颜真卿）、柳（柳公权）、欧（欧阳询）、赵（赵孟頫）四大楷书字帖，用户临摹后对比
- **技术方案**：WebView Canvas 叠加显示，半透明字帖底图 + 用户书写层
- **优先级**：🟡 P2

#### 6. 成语接龙
- **描述**：给出一个成语，下一个成语首字 = 上一个成语尾字，单机或本地双人
- **技术方案**：本地成语词库（约 10000 条），纯 Kotlin 逻辑
- **核心体验**：限时 10 秒，答不出或接错则失败，有连击奖励
- **数据需求**：成语词库 JSON（含释义、出处）
- **优先级**：🟠 P1

#### 7. 古诗词背诵
- **描述**：经典诗词填空（遮盖部分词句，用户填写），全文背诵检测
- **技术方案**：诗词 JSON 数据 + 自定义 Input 组件
- **数据需求**：小学/初中必背古诗词（约 300 首）
- **优先级**：🔴 P0

#### 8. 飞花令小游戏
- **描述**：给一个关键字（如「月」「春」），限时说出含该字的诗句，语音或文字输入
- **技术方案**：诗词数据库全文检索，关键字高亮显示
- **核心体验**：计时 15 秒，每轮难度递增，支持单人挑战和双人对战
- **优先级**：🟡 P2

### 🏮 传统文化与历史类

#### 9. 二十四节气日历
- **描述**：日历视图标注节气，点击查看该节气的习俗、农事、诗词、代表食物
- **技术方案**：KuiklyUI 自定义日历组件，节气数据 JSON
- **核心体验**：当日节气自动高亮，推送提醒「今日大雪，注意保暖」
- **优先级**：🟠 P1

#### 10. 传统节日百科
- **描述**：春节 / 元宵 / 清明 / 端午 / 中秋 / 重阳，展示习俗来历、相关诗词、食物
- **技术方案**：静态内容页，富文本 + 配图
- **优先级**：🟡 P2

#### 11. 朝代顺序记忆游戏
- **描述**：拖拽排序（夏商周→秦汉→三国→…→明清），答对后展示历史地图
- **技术方案**：KuiklyUI 拖拽交互 + SVG 历史地图
- **优先级**：🟡 P2

#### 12. 中国地图知识竞答
- **描述**：点击地图上的省份，答出省份名称 / 简称 / 省会 / 特产
- **技术方案**：WebView + SVG 中国地图（可交互），题库 JSON
- **优先级**：🟡 P2

#### 13. 传统色彩识别
- **描述**：展示「胭脂、天青、月白、缃色、松花绿」等传统色名，配色卡和诗词出处
- **技术方案**：色卡列表 + 颜色详情页，纯 KuiklyUI
- **核心体验**：每日一色，颜色命名测验（看色块猜色名）
- **数据需求**：中国传统色谱数据（约 400 色）
- **优先级**：🟠 P1

#### 14. 汉服款式图鉴
- **描述**：交领 / 对襟 / 襦裙 / 曲裾等款式图解，配朝代演变时间轴
- **技术方案**：图文详情页 + 时间轴组件
- **优先级**：🟢 P3

#### 15. 中国地名由来
- **描述**：介绍各省市地名的历史来源（如「湖南」因洞庭湖之南而得名）
- **技术方案**：地图交互 + 文字卡片
- **优先级**：🟢 P3

### 🎵 音乐与艺术类

#### 16. 民族乐器图鉴
- **描述**：二胡 / 琵琶 / 古筝 / 编钟 / 笛子等，点击播放音色片段，展示演奏姿势
- **技术方案**：图文列表 + 本地音频资源（短片段，< 10s）
- **优先级**：🟡 P2

#### 17. 京剧脸谱涂色
- **描述**：给黑白脸谱线稿涂色，学习各颜色含义（红 = 忠勇、白 = 奸诈、黑 = 刚正）
- **技术方案**：WebView Canvas 区域填色，颜色说明弹窗
- **核心体验**：涂完后对比标准脸谱，学习颜色寓意
- **优先级**：🟠 P1

#### 18. 剪纸图案生成
- **描述**：用户选择花样（喜字 / 福字 / 鱼 / 花卉），生成剪纸风格图案，可保存分享
- **技术方案**：WebView + SVG 路径裁剪效果
- **优先级**：🟡 P2

#### 19. 中国结编法图解
- **描述**：步骤动画教学（平结 / 吉祥结 / 盘扣），每步高亮当前操作绳段
- **技术方案**：WebView SVG 动画，分步骤展示
- **优先级**：🟢 P3

#### 20. 印章篆刻体验
- **描述**：用户输入名字，生成仿篆刻印章效果图，可自选印章形状和字体风格
- **技术方案**：WebView Canvas + 篆体字库
- **优先级**：🟡 P2

#### 21. 简谱练习
- **描述**：展示民歌简谱（如《茉莉花》《康定情歌》），点击音符播放对应音，跟着哼唱
- **技术方案**：WebView + Web Audio API
- **优先级**：🟢 P3

### 🍜 饮食文化类

#### 22. 中国菜系地图
- **描述**：八大菜系（鲁川粤闽苏浙湘徽）分布地图，点击查看代表菜品介绍
- **技术方案**：SVG 地图 + 菜品图文卡片
- **优先级**：🟡 P2

#### 23. 茶文化百科
- **描述**：六大茶类（绿 / 红 / 青 / 黑 / 白 / 黄），产地、泡法、功效、代表品种
- **技术方案**：图文百科页，横向分类 Tab
- **优先级**：🟡 P2

#### 24. 节气食俗
- **描述**：冬至吃饺子、元宵吃汤圆、端午吃粽子等，每个节气对应食俗故事
- **技术方案**：节气数据扩展（在节气日历基础上增加「食俗」字段）
- **优先级**：🟡 P2（与节气日历合并）

### 🧩 益智游戏类

#### 25. 华容道
- **描述**：经典滑块解谜，多关卡（从简单到高难），记录最少步数
- **技术方案**：KuiklyUI 拖拽交互，纯逻辑实现，无需外部资源
- **优先级**：🟠 P1

#### 26. 五子棋
- **描述**：人机对战（简单 / 中等 AI），配中国风棋盘皮肤
- **技术方案**：WebView + JS 五子棋 AI（Minimax）
- **优先级**：🟡 P2

#### 27. 围棋入门
- **描述**：9×9 入门棋盘，教学模式（落子 / 提子 / 气的概念），人机对弈
- **技术方案**：WebView + 开源围棋 JS 引擎（如 GnuGo 轻量版）
- **优先级**：🟢 P3

#### 28. 麻将识牌练习
- **描述**：认识麻将牌面（万 / 饼 / 条 / 字牌）和基本术语（胡 / 碰 / 杠）
- **技术方案**：图文卡片 + 翻牌记忆小游戏
- **优先级**：🟡 P2

#### 29. 洛书九宫格
- **描述**：以「洛书」为主题的数字填充游戏，行列斜三方向数字之和相等
- **技术方案**：纯 KuiklyUI 数字输入，逻辑校验
- **优先级**：🟢 P3

## 技术选型原则

1. **优先复用现有基础** — HanziWriter WebView、KuiklyUI 组件、本地 JSON 数据
2. **内容先于交互** — 先有数据和内容，再做精致交互动画
3. **离线优先** — 所有核心内容打包在 assets，不依赖网络
4. **渐进增强** — 每个功能独立页面，互不依赖，便于单独迭代
